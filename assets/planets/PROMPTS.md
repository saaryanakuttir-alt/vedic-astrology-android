# Image prompts for the nine planets (Navagraha)

These pictures appear in **Learn Astrology → Lesson 3 (The 9 planets) → Meet the nine planets**.
Each one is based on how the classical texts describe the planet as a deity (Matsya Purana ch. 94,
Vishnudharmottara Purana and the navagraha dhyana verses), so the colours, objects and vehicles match the text
beside it in the app.

## How to add them
1. Generate each image as a **square, 1024 × 1024**.
2. Save it with the file name given below (`.png` or `.jpg`) in `android_app/assets/planets/`.
3. Commit and push (or ask Claude to). The app shows a picture only when its file is there, so you can add them one at a time.

Keep the files under about 300 KB each (JPG at quality 85 is fine) so the APK stays small.

## Shared style (already included in every prompt below)
Traditional Indian devotional painting in the Tanjore/Mysore style, gold-leaf details, rich jewel colours,
full figure centred, calm and dignified expression, deep indigo night-sky background with faint stars
(it matches the app's dark theme), square composition, highly detailed, no text.

**Negative prompt (use for all):** text, letters, words, watermark, signature, frame, border, extra limbs,
extra fingers, deformed hands, distorted face, modern clothing, photorealistic, 3D render, cartoon, blurry.
